# Chenoot 1.3.0

This release is about getting started and about room to work. It changes nothing
about how items are written, checked, or selected, so an instrument built in
1.3.0 comes out the same as one built in 1.2.0.

## Use the Ollama you already have

If you already run Ollama, Setup now looks for it before offering to install
anything. It tries your saved address and the usual local port on its own, and
you can type an address if yours runs on another port. When it finds one, it
lists the models you have already pulled, so nothing is downloaded twice. Only
an Ollama on your own computer is accepted. When both steps are done, Setup
shows a check in the bar and a button into the Workspace, at the top of the
page and again after step two.

## Room to write and read

You can drag the inner edge of either side column in the Workspace to make it
wider or narrower, or use the arrow keys once the edge has focus. Double click
an edge to put it back. The widths are kept for next time.

A text field in the brief now opens in the middle of the window while you type
in it, over a dimmed page, so a long answer is easy to read. Click outside it or
press Escape and it goes back into the column with your answer kept.

## Clearer questions

Construct, target population, and survey purpose each have a short explanation
and an example under the label. In plain terms they are what you want to
measure, who you are asking, and why. Help and the walkthrough use the same
words.

## Changing a finished instrument

Edit the brief brings a finished instrument's brief back into the form, and
that includes a run you reopened from the Library. Back to the finished
instrument returns to it without changing anything, so looking at the brief
costs nothing.

## Easier to read

The finished instrument opens with a title, a one line summary, and one line of
details, and its section headings are in sentence case. Good for and Watch for,
and Does well and Struggles for each model, now have marked headings in place
of a colored bar. The examples under Response formats and Item types look like
survey items, with ordered scales running from the least at the bottom to the
most at the top. The Chenoot name in the bar always leads to the home page,
which lists your latest runs just under its opening.

## Installing

Nothing about installing has changed. The macOS downloads are signed and
notarized and open with the one question macOS asks about every downloaded app.
Windows and Linux downloads install as before. See the README for each platform.

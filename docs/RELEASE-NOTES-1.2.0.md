# Chenoot 1.2.0

This release changes how Chenoot looks and how you move through it. It changes
nothing about how items are written, checked, or selected, so an instrument built
in 1.2.0 comes out the same as one built in 1.1.0.

## One workspace

Writing a brief, watching a run, and reading the finished instrument used to be
three separate screens, and the instrument disappeared from view at each
handoff. They now share one screen. Your brief and a plain list of the steps sit
on the left, with how long each took. The instrument sits in the center as a
sheet that adds each step's result as it finishes, and the details of the run
sit on the right. Every control from the earlier screens is still there.

## A shorter bar

The navigation bar has seven destinations where it had nine. Past runs is now
the Library. Response formats and Item types share one Reference destination
with tabs. After your first instrument, Chenoot opens on a home screen with your
recent runs and one button to build another, and the full introduction is one
click away.

## Fewer surprises

If setup is not finished, the bar and the new instrument form both say so before
you start filling anything in. Required fields stand out from optional ones.
Settings asks before closing with changes you have not saved. On the results
screen, the two controls that change every item are buttons, apart from the two
links that only explain.

## A new icon

The icon is now three rows of radio buttons with one chosen in each, on a lit
tile. The rings are heavier than they would be on screen so they still read at
the size a Dock renders. macOS keeps app icons in a cache, so after you install
this version the Dock may show the old one until you run killall Dock in
Terminal.

## Installing

The macOS downloads are signed and notarized and open with the one question
macOS asks about every downloaded app. Windows and Linux downloads install as
before. The Linux AppImage is now built on Ubuntu 24.04, so it keeps running on
current distributions. See the README for each platform.
